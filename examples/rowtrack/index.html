Write music in rows. In your terminal.

Rowtrack is a pattern tracker: you type notes into columns, and they play from top to bottom. Five channels, a built-in synth and sampler, and the same keys trackers have used since 1987.

cargo install rowtrack

Click any cell in the KICK·SNR column to add or remove a hit. The pattern is “Low Tide”, 64 rows at 125 BPM, speed 6.

10

One row, four columns per channel.

C-4 05 30 A04
└─┬─┘   └┬─┘  └┬─┘  └─┬──┘
  │      │     │      └─ effect: slide volume down by 4 each tick
  │      │     └──────── volume: 30 of 40 (hex), about three quarters
  │      └────────────── instrument 05: the lead pulse
  └───────────────────── note: C in octave 4

A row cell reads C-4, 05, 30, A04: note C in octave 4, instrument 5, volume 30 hex, and effect A04, which slides the volume down by 4 on each tick.

Time runs down the screen. Each row is one step, and the speed says how many ticks a row lasts. At 125 BPM and speed 6, a row is 120 milliseconds, and four rows make a beat.

Empty cells mean “keep doing what you were doing”. === releases a note. Everything else is typed, so a whole song is a text file you can diff, grep and send in a chat message.

Your keyboard is two octaves of piano.

The bottom row is the lower octave, the row above it the upper one, with sharps on the keys between. Turn sound on, then press the keys or click them.

40

Install it. Open a pattern.

macOS, Linuxbrew install rowtrack
Any, with Rustcargo install rowtrack
Windowswinget install rowtrack
Thenrowtrack low-tide.rt
  • Any terminal at 80 × 24 or larger, with or without colour.
  • Plays through the system audio device, or renders silently to WAV with --render.
  • Opens .rt (plain text), .it, .xm and .mod. Exports WAV, FLAC and MIDI.
  • Works over SSH with --remote-audio streaming sound back to your machine.

3F Rowtrack is a fictional product, built as a worked example of Kern. The pattern, synth and keyboard on this page are real and run in your browser.
